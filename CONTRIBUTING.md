# Contributing

Talaris is licensed under the **GNU General Public License, version 3 only**
(`LICENSE`). Its owner also licenses it on other terms, including commercial
ones.

**Before a contribution can be accepted, its author has to agree to the
Contributor License Agreement in `CLA.md`.** You keep the copyright in what you
write; the agreement gives the owner the license needed to keep offering
Talaris under both the GPL and other terms. Without it, every outside
contribution would need its author's separate permission before Talaris could be
licensed any other way.

Say in your pull request that you have read `CLA.md` and agree to it.

## Source files

Every source file starts with:

```
SPDX-License-Identifier: GPL-3.0-only
Copyright (c) <year> Jeff Moore
```

in whatever comment syntax the file uses.

**"Only," not "or later."** "Or later" would let a future version of the GPL,
written by someone else, apply to Talaris without the owner choosing it.
